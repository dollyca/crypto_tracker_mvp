# 💰 Crypto Tracker MVP

> 一個能夠自動追蹤加密貨幣幣價變動的**全自動化可視化網站**，支援多幣種、動態圖表、每日更新，並部署於 Render 雲端。

🌐 **Demo 網址**：  
 [https://crypto-tracker-mvp.onrender.com](https://crypto-tracker-mvp.onrender.com)

---

## 專案亮點

- **每日自動更新幣價資料**（BTC, ETH, USDT 等）
- **支援 24 小時漲跌幅顯示**，紅綠箭頭標示漲跌
- **幣種切換選單**，快速查看任一幣種走勢
- **動態折線圖（Plotly）**，滑鼠可互動縮放，支援手機瀏覽
- **全自動化部署流程（CI/CD）**，免本地執行
- **雲端部署於 Render 平台**

---
